# LightX2V Windows v0.4.3

- First-time setup offers automatic component downloads after a completed search finds no compatible environment. Verified local environments can be selected while the search runs.
- General settings includes **Application updates**. The app checks Stable when available and checks Latest before the first Stable release. It verifies the downloaded package and applies it after exit.
- Uninstall previews matching desktop shortcuts, retries temporary file locks and reports any remaining items.
- Published ZIP folders include the source commit so different builds can be extracted side by side.
- Model preparation and generation settings use the Mac app's fade and height transition, following the Windows animation preference.
