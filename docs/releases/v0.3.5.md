# v0.3.5 · First Windows preview release

Native Windows x64 image creation with local Qwen-Image-2.1-Turbo inference. Once initial setup is complete, you can enter the workspace without generating a mandatory test image.

## Features

- Four-step setup wizard: choose a directory, scan the GPU and prepare the environment, download models in one click, and start creating.
- AMD ROCm and NVIDIA CUDA preview environments, with official driver checks and installation guidance.
- Text-to-image generation, editing with up to three reference images, 512/1K/2K output, and aspect-ratio presets.
- PE-T2I / PE-I2I prompt enhancement, resumable downloads, and integrity checks.
- Progress and cancellation, task logs, history, copy/export, and settings reuse.
- The same three-column layout as the Mac app, with collapsible sidebars, settings, and Chinese/English interface languages.
- v0.3.5 fixes GPU detection that depended on a single CIM query: native device enumeration takes priority, with nvidia-smi / CIM fallbacks, retained errors, and diagnostics that can be copied. Detection failure does not imply a missing driver.

## Current limitations

- AMD hardware validation covers Radeon 8060S; other AMD GPUs have not completed full acceptance testing.
- Full CUDA installation and image generation still require validation on RTX hardware. For 8 GB VRAM + 32 GB system RAM, start by testing 512 output with enhancement disabled; successful generation is not guaranteed.
- The app uses BF16 models, with no FP16/quantized fallback for RTX 20 series and no CPU-only inference support.
- H3 video and multi-model selection are not yet integrated.
- The app is unsigned. Obtain it only from trusted release sources and keep system security settings enabled.

## Distribution files

- `LightX2V-Windows-0.3.5-win-x64.zip`: extract the entire archive, then run `LightX2V.Windows.exe`.
- `LightX2V-Windows-0.3.5-win-x64.zip.sha256`: integrity checksum.
- GitHub's automatically generated source archives: for developers, not runnable app packages.

The first release is marked **Pre-release** on GitHub. Do not mark it as Stable. Model weights, personal settings, and development QA data are excluded from the public source release. The portable package includes the pinned third-party components required at runtime and their licenses.
