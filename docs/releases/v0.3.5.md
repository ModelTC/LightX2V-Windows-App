# v0.3.5 · 首个 Windows 内测版

原生 Windows x64，本地 Qwen-Image-2.1-Turbo 创作。首次配置完成后即可进入工作区，无需强制生成测试图片。

## 包含功能

- 四步新手向导：选择目录、扫描显卡并准备环境、一键下载模型、开始创作。
- AMD ROCm 与 NVIDIA CUDA 预览环境；官方驱动检查与安装指引。
- 文生图、最多三张参考图编辑、512/1K/2K、比例预设。
- PE-T2I / PE-I2I 提示词增强、下载续传和校验。
- 进度与取消、任务日志、历史、复制/导出和参数复用。
- 与 Mac 版一致的三栏布局、可折叠侧栏、设置页及中文/英文。
- v0.3.5 修复显卡检测依赖单次 CIM 查询的问题：原生设备枚举优先，nvidia-smi / CIM 回退，保留错误与可复制诊断；检测失败不等于缺少驱动。

## 当前限制

- AMD 实机验证范围是 Radeon 8060S；其他 AMD 显卡没有完整验收。
- CUDA 完整安装及出图仍待 RTX 实机验证。8 GB 显存 + 32 GB 系统内存建议先测 512、关闭增强，不能保证可完成生成。
- 使用 BF16 模型，未提供 RTX 20 的 FP16/量化回退，不支持纯 CPU 推理。
- H3 视频与多模型选择尚未接入。
- 程序未签名；只从可信发布来源获取，不更改系统安全设置。

## 分发文件

- `LightX2V-Windows-0.3.5-win-x64.zip`：完整解压后运行 `LightX2V.Windows.exe`。
- `LightX2V-Windows-0.3.5-win-x64.zip.sha256`：完整性校验。
- GitHub 自动生成的源码压缩包：供开发者使用，不是可运行安装包。

首版在 GitHub 中使用 **Pre-release（内测）** 标记。不要标为 Stable。模型权重、个人配置和开发 QA 数据不随源码发布；便携包包含运行必需的固定第三方组件及其许可证。
