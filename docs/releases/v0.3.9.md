# v0.3.9 · 启动交互、提示词复制与结果图参考

## 打开工作区后即可操作

已有完整配置的用户打开 App 后，不再自动启动耗时的 Python / GPU 探测并锁住设置与侧栏。可以立即输入提示词、调整参数、打开设置和添加参考图。

点击生成后才进行必要的环境预检；通过后再启动图像任务，同一会话可复用已验证的相同环境。预检沿用发送 / 停止控件，可以取消，失败或取消保留草稿。更换配置或退出时，旧检查的结果不能覆盖新配置。

首次安装缺少环境或模型时仍按现有向导准备资源。空提示词、缺少必要资源，以及用户已经发起的安装、下载或生成任务，仍按实际状态处理，不把未验证的 GPU 标记成检查通过。

## 提示词与结果操作

- 已发送提示词可用鼠标选中，支持 Ctrl+C 与右键复制；保留原黑色气泡、字体和排版，历史内容只读。
- 移除生成结果下方的“复用参数”按钮。
- 在原按钮位置提供“图生图”入口：把当前生成图追加为参考图，保留草稿提示词、已有参考图、尺寸、seed 和增强选择，不自动生成。
- 图片经现有导入流程保存独立副本；Windows 的参考图上限仍为 3 张。生成或预检忙碌时不会修改所属请求的参考图。
