# v0.3.9 · Interactive startup, prompt copying, and generated-image references

## Use the workspace as soon as it opens

For users with a complete existing configuration, opening the app no longer automatically starts a lengthy Python / GPU probe that locks settings and sidebars. You can immediately enter prompts, adjust parameters, open settings, and add reference images.

Necessary environment preflight checks run only after you click Generate. Image generation starts after the checks pass, and the same validated environment can be reused within a session. Preflight uses the existing generate / stop control and can be cancelled; failures and cancellation preserve the draft. After a configuration change or exit, stale check results cannot overwrite the new configuration.

First-time installations with a missing environment or models still prepare resources through the existing wizard. Empty prompts, missing required resources, and installation, download, or generation tasks already initiated by the user continue to be handled according to their actual state. An unverified GPU is not marked as having passed its check.

## Prompt and result actions

- Sent prompts support mouse selection, Ctrl+C, and the context-menu Copy action. The original black bubble, font, and layout are retained, and history remains read-only.
- The **Reuse settings** button below generated results is removed.
- **Use as reference** replaces that button: it appends the generated image as a reference while preserving the draft prompt, existing reference images, dimensions, seed, and enhancement selection. It does not start generation automatically.
- Images are saved as independent copies through the existing import flow. The Windows reference-image limit remains 3. Generation or preflight activity does not modify the reference images belonging to the active request.

This release retains v0.3.8 pread / owned-buffer reads, automatic resource planning, and generation parameters. Startup responsiveness is improved without reducing output dimensions or disabling enhancement.
