# v0.3.6 · Initial setup fixes

## Continue directly after automatic installation

After a newly installed environment passes an actual GPU check, the app immediately adds it to the available-environment list, selects and saves its Python path, and proceeds to model preparation. No manual search is required. The same check result is reused to avoid launching a duplicate GPU environment check. The first check of a newly installed environment allows up to 180 seconds for initial imports and initialization; ordinary searches still allow 90 seconds. Failed checks, backend mismatches, and cancellation do not mark the environment as ready.

## Show only the wizard during initial setup

First launch no longer shows a workspace disabled by a modal window. The wizard has its own taskbar window and can be minimized normally; minimizing during a download does not stop it. The workspace opens only after environment and model setup is complete and the user clicks **Start creating**. Closing the initial wizard exits the app. On the next launch, preparation of incomplete models can continue. Users with a complete existing configuration still open the workspace directly.

## Validation scope

New offscreen regression checks cover automatic environment adoption after installation, a single environment check, failure and cancellation, the initial window lifecycle, minimizing during downloads, exit, and re-entry. CUDA installation results were validated with an injected RTX 4070 fixture; a full environment installation and image-generation run were not repeated on that laptop. The native AMD environment and wizard were checked again on the development machine. Inference code, models, pinned dependencies, and sampling settings were unchanged.

CUDA remains preview support, with full RTX image generation still pending hardware acceptance testing. Existing v0.3.5 packages and checksum files remain available. To upgrade, extract the entire new version and continue using the existing working directory.
