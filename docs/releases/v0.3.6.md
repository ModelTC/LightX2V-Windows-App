# v0.3.6 · 首次配置流程修复

## 自动安装后直接继续

新安装的环境完成实际 GPU 检查后，立即回填可用环境列表、选中并保存 Python 路径，然后进入模型准备，无需再手动搜索。复用同一次检查结果，避免重复启动 GPU 环境检查。新安装环境的首次检查允许最多 180 秒，兼顾首次导入和初始化；普通搜索仍为 90 秒。检查失败、后端不匹配或用户取消时不会把环境标记为就绪。

## 首次配置只显示向导

初次使用时不再先显示一个被模态窗口禁用的工作区。向导是独立的任务栏窗口，可正常最小化；下载期间最小化不停止下载。完成环境与模型配置、点击“开始创作”后才打开工作区。直接关闭首次向导会退出应用；重新启动后可继续准备未完成的模型。已有完整配置的用户保留直接打开工作区的行为。

## 验证范围

新增离屏回归检查覆盖安装后自动选用环境、单次检查、失败与取消、首次窗口生命周期、下载中最小化、退出和重新进入。CUDA 安装结果使用注入的 RTX 4070 夹具验证，没有在该笔记本上重新执行完整环境安装或出图。AMD 原生环境及向导在开发机复核；推理代码、模型、固定依赖与采样配置未更改。

CUDA 仍为预览支持，完整 RTX 出图仍待实机验收。已有 v0.3.5 安装包与校验文件继续保留；升级完整解压新版，沿用原来的工作目录即可。
