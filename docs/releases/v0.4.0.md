# v0.4.0 · Standard-model workflow and Mac parity

This Latest development build follows Mac Stable `65acaee0c063200651629cb21df7c46711687e65` and the supplied desktop references. INT8 and in-app update checking remain deferred. Windows Stable has not been promoted.

## Creation and settings

The existing four-step Windows first-run assistant is retained, including graphics-driver guidance, environment preparation, model downloads, cancellation and recovery. Completing it selects Standard without requiring a sample generation. General settings uses three compact cards, configuration badges and a link back to the assistant. Searching or preparing an edited workspace does not replace the active workspace before Save.

The workspace has a family/Standard model selector, compact model cards with PE-T2I/PE-I2I labels, four primary image actions and independently collapsible inspector sections. Idle enhancement cards are muted while enhancement is off; active transfers remain stoppable. Check and repair remains in Download guide, and Export is available from the image context menu. Automatic download routing is retained in a single-row source selector.

Up to eight references can be selected, dropped, pasted or added from a result. C# and Python consume the same 100 MB / 40 megapixel policy. Mixed damaged batches roll back, deliberate references keep independent identities, and concurrent imports are queued. Embedded-Python import paths and UTF-8 handling are covered by real importer checks.

Each creation remembers its resolution, ratio and enhancement choice, including a new creation that has not generated an image. Reuse selects the source creation and prepares a new random-seed draft. Enter sends, Shift+Enter inserts a newline, and IME composition does not submit. Submission shortcuts do not stop active inference. History selection updates the log target even while the log panel is hidden, and streaming preserves the reader's scroll position.

## Uninstall and distribution

Uninstall offers model weights, workspace data, and application/settings groups. It shows exact targets before confirmation. Managed environments and sources require ownership markers; external resources default to unchecked. Protected paths, directory links, overlapping retained resources and changed plans are rejected. Application removal follows the package manifest and preserves additional files placed in the program directory. A verified helper waits for the parent to exit, records its result and cleans its program copy.

Successful builds update one fixed Latest download. Stable is manually promoted from verified Latest bytes without rebuilding. CI compiles, verifies the complete package and pinned payloads, and publishes; behavioral and hardware checks run locally. Publication regressions cover failed uploads, stale runs, failed replacement/ref/metadata updates and recovery of an interrupted first draft.

## Validation scope

- Windows Python regressions: 171 tests, 166 passed and five opt-in GPU/full-model checks skipped. Real CPU tensor/checkpoint and image import cases ran on Windows.
- The WPF regression suite covers startup, recovery, downloads, creation settings, imports, logs, uninstall fixtures and the four supplied inspector layouts. Offscreen renders are distinguished from interactive display-scaling and IME acceptance.
- Through the actual app view model on AMD Radeon 8060S, a 512-square Standard text-to-image task completed in 35.92 seconds, followed by eight-reference Adaptive editing in 116.41 seconds. Both wrote valid PNGs. Enhancement was off. These are individual samples, not performance guarantees.
- The packaged maintenance process has been exercised only against isolated disposable targets, including preservation and helper cleanup.

RTX acceptance, the full 512/1K/2K and enhancement/reference matrix, and physical 100%/150%/200% display-scaling and IME interaction checks remain required before the first Stable. Existing v0.3.x hardware results retain their original version and scenario scope. Models, inference dependency pins and automatic resource-planning policy are unchanged.
