# v0.3.8 · Windows 权重读取稳定性修复

## 修复文本编码阶段的高风险映射路径

v0.3.7 在 RTX 4070 Laptop 8 GB / 32 GB 内存的 512 文生图测试中，自动选择流式后已完成模型初始化，但在文本编码阶段以 `0xC0000005` 原生崩溃。异常地址与词表在 safetensors 文件中的偏移一致；同配置独立重跑曾成功。该证据支持 Windows 全文件映射异常的判断，尚不能仅凭报告认定是 `safe_open` 上下文提前关闭。

本版移除 App 流式适配器的映射读取：

- checkpoint 文件头用普通文件 I/O 建立索引，校验形状、dtype、字节范围和文件变化。
- 编码器词表只读取 token 对应的去重行，结果保持原顺序和形状；不复制整张词表。真实官方文件专项中，8 个唯一行仅读取 64 KiB payload，完整 embedding 为 1,244,659,712 字节。
- DiT / 文本层保留单个 CPU staging block 和单个 GPU block，显式读入自有张量；静态权重和视觉组件也使用自有存储。
- Windows worker 在 LightX2V / Transformers 导入前，为普通 safetensors 加载选择 `pread`，绕开 PyTorch 的全文件 COW 存储路径。固定版本 safetensors 的 metadata 初始化仍可能使用受检查的 Rust 映射，不能据此声称所有普通加载完全无映射。

Windows 写时复制映射会消耗 commit；可用物理内存、系统提交余量与显存不是同一指标。因此旧报告中的空闲物理内存与没有 CUDA OOM，不能完全排除映射阶段资源不足。源码依据与边界见 [Windows 权重读取说明](../windows-checkpoint-io.md)。

## 保留自动资源规划和现有界面

AMD 与 NVIDIA 共用自动规划逻辑。容量充足仍使用驻留路径，受限时才流式，不增加用户手选模式。BF16 权重、8 步采样、输出尺寸、参考图、增强设置、历史和交互流程保持原有行为。

本版不更换 Python、PyTorch、safetensors 的锁定版本，也不修改所捆绑的 LightX2V 源码归档。升级可复用 v0.3.7 的环境、模型、运行源码和工作区，无需删除目录或重下模型。

## 崩溃与遥测诊断

- worker 提前开启 `worker-fault.log`，覆盖模型适配器导入之前的原生故障；正常运行时可能只有进程身份信息。
- `worker-start.json` 记录启动与读取策略，`worker-exit.json` 记录实际退出码、十六进制 NTSTATUS 和 worker PID。原生崩溃不会再仅展示末尾参数 JSON。
- 只记录实际存在、可访问并匹配 PID / 时间的 dump。App 不开启 WER、不修改注册表、不复制或上传转储，不保证系统一定生成 dump。
- 主机与阶段遥测新增 run/session、producer/observed 身份；仅在事件成功写入日志后聚合，过滤 PID 复用。系统启动以来的 commit 峰值独立保存为历史指标。

## AMD 开发机验证

本版在 Radeon 8060S / Windows 11 上完成：

- 135 项 Python 检查全部通过，包含真实官方 checkpoint 的两层 DiT / 文本编码器 GPU 数值对照、真实 GPU pread、官方词表行读取、Windows DXGI 与崩溃诊断测试。
- 不安装第三方推理依赖的标准库检查：102 项执行通过，33 项依赖或实机专项明确跳过。
- 四个 C# 项目编译成功，30 项界面启动离屏检查通过，界面截图目检正常。
- 三次独立 worker 的流式 512 文生图、普通驻留 512、流式 512 参考图编辑、流式 1K、部分 GPU 提示词增强与流式 512 串联，均生成可解码 PNG。
- 对应的 512、1K 和参考图编辑输出与原有样本 PNG 字节完全一致。
- 本机流式 512 pipeline 约 57.2–57.7 秒，参考图编辑约 70.4 秒，1K 约 145.7 秒；不包含模型加载与 Python 启动。驻留 512 仍自动选择 `full_resident`，本机样本 pipeline 约 14.2 秒。这些是样本耗时，不是对 RTX 的速度承诺。
- 七个实际任务的主机与 worker 摘要，已逐字段对照同会话 JSONL 的峰值、最小值和样本数，一致。

受限资源分支通过测试程序提供的预算在 AMD 开发机执行；这不等于该机器实际只有 8 GB 独显 / 32 GB 内存，也不等于完成冷缓存压力测试。

**v0.3.8 的 NVIDIA CUDA / RTX 实机复测仍待完成。** 建议先关闭增强，用同一提示词、seed 和 512 / 1:1 连续生成并多次完全退出重启，至少记录 5 次任务；稳定后再测试 1K、参考图和增强。失败时保留完整任务目录。本版没有重新执行完整 2K 文生图，不宣称所有 8 GB 设备或全部尺寸均已验收。

完整解压新版到新的程序文件夹，继续选择原工作区。具体日志说明见 [自动资源规划](../automatic-resources.md)。
