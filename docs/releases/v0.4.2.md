# v0.4.2 · First use, automatic discovery and Mac interaction parity

Reference: Mac Stable `65acaee0c063200651629cb21df7c46711687e65`. Inference remains official LightX2V 0.6.1 (`43c6a11bb65b7357f06e9603fa92249bc16b484e`) with the existing Windows patch. Dependency pins, resource planning and eight-reference support are unchanged.

## Changes

- Retain the four-step Windows wizard, remove redundant choices and legacy import, automatically check hardware and discover compatible existing environments. Preparation still requires confirmation. Unusable candidates cannot be selected.
- Validate the target metadata of cache file links on Windows, including tokenizer-cache invalidation when a link changes. Directory-link traversal remains excluded.
- Discover complete models at the current paths, workspace and adjacent model folders, app-adjacent folders and HF/ModelScope caches, then local fixed disks. Searches are read-only, cancellable, deterministic, exclude protected directories and directory links, and cannot overwrite manual edits or a new workspace. Network and removable drives require explicit selection. Inaccessible locations are reported as partial search coverage.
- Share smoothed download speed and remaining-time formatting. Environment totals include Python and wheels, verified caches and resumed prefixes; checking, extraction and installation do not show a download countdown. Automatic source selection stays within pinned manifest URLs and preserves checksum verification.
- Share rounded language menus and anchored download guides for all three models. Guides contain the repository, relative PowerShell command, source link and copy feedback. General settings keeps three compact cards, a separate environment dialog and save/cancel drafts; language remains immediate.
- Align the composer, circular icon-only stop control, model badge, output-size typography, breadcrumb and result action spacing. Missing enhancement requirements remain visible through the send tooltip and model state.
- Save complete `run.log` files, including live enhancement diagnostics. Preview the last 90,000 UTF-8 bytes, preserve scroll position while reading, resume following at the bottom, and locate the actual log file in Explorer. Older stage logs remain readable.
- Increase language-selector height and vertical text space after desktop feedback; retain a readable command viewport above its horizontal scrollbar.

## Validation scope

Local Python regression, Windows WPF simulation/layout regression and interactive AMD desktop checks are separate from GPU acceptance. AMD acceptance covers isolated first use, automatic environment reuse, discovery of the existing three models, real Standard text-to-image, eight-reference Adaptive editing, both enhancement workflows, stopping and reopening history. Original workspaces, models and installed environments are preserved.

The layout checks cover Chinese/English and viewport sizes representative of 100%, 150% and 200% scaling. Interactive desktop checks run at the host's existing display scale; they do not change Windows display or security settings. RTX and additional physical monitor/scale combinations still need user-assisted acceptance using [the testing guide](../testing.md).

Latest only. INT8, in-app updates and Stable promotion remain deferred. Release metadata supplies the exact published source commit and package SHA-256.
